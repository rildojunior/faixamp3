# Novidades

As novidades de cada versão do FaixaMP3. O texto de cada versão vira a descrição da release no GitHub e aparece
no aviso de atualização dentro do app.

## Próxima versão

- Playlists, álbuns e músicas adicionados por link agora aparecem na lista com o nome de verdade, em vez
  do código do link.
- Em instalações novas, o app já vem com 7 downloads simultâneos, para baixar mais rápido. Quem já usa o app
  continua com o valor que escolheu.

## 0.2.0

- O FaixaMP3 agora se atualiza sozinho: ao abrir, ele verifica se há uma versão nova, baixa em segundo plano e
  pergunta se você quer reiniciar para usar. Se escolher "Depois", a atualização é instalada quando você fechar o
  app.
- O aviso de atualização mostra as novidades da versão nova.

## 0.1.1

- Novo botão **Limpar lista**, embaixo da lista de músicas: tira da tela as músicas do último download. Os
  arquivos baixados continuam na pasta.

## 0.1.0

- Primeira versão.
